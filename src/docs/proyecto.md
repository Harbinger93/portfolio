### Proyectos Destacados (Portafolio)

## 📊 Dashboard de Gestión & Analítica Avanzada (GA4 Portal)

Descripción Breve

Portal de administración y productividad integral que combina analítica avanzada con herramientas de gestión interna. Además de centralizar y procesar métricas de Google Analytics 4 (GA4), la plataforma cuenta con un planificador de contenidos por usuario, una interfaz interactiva basada en drag-and-drop, una bóveda de contraseñas segura para el equipo, generación de reportes especializados a medida y un módulo de carga de archivos multimedia para centralizar manuales de procesos internos.

Tech Stack
Frontend: Astro, React.js, Tailwind CSS.
Backend & Auth: Supabase.
Infraestructura & CI/CD: Vercel, GitHub.
Analytics: Google Analytics 4 (GA4), Google Tag Manager (GTM).

## 🚀 Adiwapp (SaaS de Gestión y Pagos Multi-tenant)

Descripción Breve

Plataforma SaaS integral orientada a la administración de inventario y al procesamiento de pagos seguros en un entorno multi-inquilino (multi-tenant). El sistema está diseñado para permitir a múltiples comercios gestionar de forma totalmente aislada, fluida y segura sus flujos de facturación y stock en tiempo real. Cuenta con un diseño enfocado en la usabilidad del panel de administración (Backoffice) para optimizar la toma de decisiones del comerciante.

Tech Stack

Frontend: Astro, React.js, Tailwind CSS.
Backend & Auth: Supabase.
Infraestructura & CI/CD: Vercel, GitHub.

## ✈️ Koyobo (Plataforma Web para Agencia de Viajes)

Descripción Breve

Desarrollo y reestructuración digital de la plataforma web interactiva para la agencia de viajes Koyobo. El proyecto consistió en crear una experiencia de navegación moderna, fluida y sumamente visual para la exploración y reserva de destinos turísticos. La plataforma desacopla la gestión de contenidos turísticos del diseño final para garantizar un rendimiento de carga excepcional y una consistencia de marca impecable en todos los dispositivos.

Tech Stack
Frontend: Astro, React, Tailwind CSS.
Backend / CMS: WordPress Headless (CMS Desacoplado).

## 🏢 Intranet Corporativa para Cliente Europeo

Descripción Breve

Desarrollo de una intranet corporativa segura y a medida para una organización en Europa, diseñada para centralizar flujos de trabajo, documentación interna y comunicación interdepartamental. Destaca por la integración fluida de un mapa interactivo personalizado utilizando Leaflet.js para la geolocalización de recursos corporativos y un consumo eficiente de datos a través de la API nativa de WordPress.

Tech Stack
Backend / CMS: WordPress (como Headless CMS / Custom Development).
Interactividad y Mapas: Leaflet.js.
Comunicación: WordPress REST API.

## 🤝 SomosMigrantes - "ComoTu" (Plataforma Digital de Extranjería en España)

Descripción Breve

Desarrollo frontend de la nueva plataforma interactiva y de alta conversión para SomosMigrantes - ComoTu, un servicio profesional especializado en la asesoría y regularización de trámites de extranjería en España.
La plataforma cuenta con un diseño de UI moderno, limpio y de alta confianza (esquema de color verde esmeralda y blanco), una arquitectura de navegación fluida con pestañas y un catálogo interactivo con filtros dinámicos en tiempo real (según el tipo de trámite: Arraigo, Nacionalidad, Residencia, Trabajo o Familiar como se muestra en Trámites-de-Extranjería-en-España-SomosMigrantes-ComoTu.jpg). Incluye una sección avanzada de preguntas frecuentes desplegables tipo acordeón (Preguntas-Frecuentes-Extranjería-España-SomosMigrantes-ComoTu.jpg), un panel de testimonios estructurado con filtros por trámite (Testimonios-de-Clientes-SomosMigrantes-ComoTu.jpg), soporte directo con WhatsApp, selector nativo de Modo Oscuro (dark mode), formulario de contacto validado en cliente (Contacto-Asesoría-de-Extranjería-SomosMigrantes-ComoTu.jpg) y mapas interactivos geolocalizados.

Tech Stack
Frontend: Astro, React.js, Tailwind CSS.
Componentes & UI: shadcn/ui.
Mapas: mapcn (Mapas Interactivos).
Validación de Datos: Zod.
Backend & Auth: Supabase.
Infraestructura & CI/CD: Vercel, GitHub.
